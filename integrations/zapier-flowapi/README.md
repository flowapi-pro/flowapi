# Flow API for Zapier

Trigger: **New Incoming WhatsApp Message** (instant, REST hook).
Actions: **Send WhatsApp Message**, **Send WhatsApp File**.

## Publish (one time, by the Flow API owner)
```
npm install -g zapier-platform-cli
zapier login
npm install
zapier register "Flow API"
zapier push
```
Then invite users from the Zapier developer dashboard, or submit for public listing.
