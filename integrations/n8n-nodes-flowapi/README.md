# n8n-nodes-flowapi

WhatsApp for n8n with [Flow API](https://flowapi.pro).

- **Flow API (WhatsApp)** — send text, files, locations and polls; read chat history and recent incoming messages; check numbers; mark chats as read.
- **Flow API Trigger (WhatsApp)** — start a workflow on incoming messages, delivery statuses, connection changes or calls. Activating the workflow sets your instance's webhook automatically.

## Install
In n8n: **Settings → Community Nodes → Install** → `n8n-nodes-flowapi`.

## Credentials
Instance ID and API Token from the Credentials tab of your number in the Flow API console.

Green API users: the same Instance ID / token format, so moving over is a credential swap.
